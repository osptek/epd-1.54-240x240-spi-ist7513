## Overview

OSPTEK **1.54″ 240×240 EPD** is a **SPI** six-color e-paper module driven by **IST7513**. Suited to anti-loss tags, phone accessories, and low-power IoT displays.

Spec ID (repository name): `epd-1.54-240x240-spi-ist7513`

Current module version: **EPD0154A10A3**. Electrical and mechanical details follow [`docs/EPD0154A10A3.pdf`](./docs/EPD0154A10A3.pdf).

## Specifications

| Item | Spec |

| Resolution | 240×240 |
